# IBM HR Employee Attrition Analysis

## Project Overview

Analysis of employee attrition using Python, MySQL, and Tableau.

## Business Problem

The objective of this project is to identify the major factors
associated with employee attrition and provide actionable
business insights.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Tableau

## Project Workflow

1. Data Understanding
2. Data Cleaning
3. Exploratory Data Analysis
4. SQL Analysis
5. Tableau Dashboard
6. Business Insights
7. Recommendations

## Key Analysis

- Overall employee attrition
- Attrition by department
- Attrition by job role
- Attrition by age group
- Attrition and overtime
- Attrition and job satisfaction
- Attrition and income
- Attrition by years at company
